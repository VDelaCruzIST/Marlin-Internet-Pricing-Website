# Marlin Internet Pricing Website

## Overview
This repository contains an Internet service provider (ISP) pricing website developed as part of my coursework while pursuing a Bachelor of Business Administration in Information Systems and Technology (IST).

The website presents multiple Internet service plans and pricing options using responsive web design techniques and structured data tables. The project demonstrates the use of HTML tables, responsive navigation menus, custom fonts, media queries, and modern CSS styling.

## Features
* Internet service pricing website
* Responsive navigation menu
* Service plan comparison table
* Mobile and desktop layouts
* Custom web font integration
* Data-driven pricing display
* Styled table formatting and presentation
* Responsive user interface design

## Technologies Used
* HTML5
* CSS3
* Responsive Design
* Media Queries
* CSS Tables
* Custom Web Fonts

## Project Files
* `mi_pricing.html` – Main pricing webpage
* `mi_reset.css` – CSS reset stylesheet
* `mi_styles.css` – Website styling and responsive design
* `mi_tables.css` – Table formatting and presentation styles
* `mi_data.txt` – Pricing plan data source
* Custom font files (`.ttf`, `.woff`)

## Skills Demonstrated
* Front-end web development
* Responsive web design
* HTML table creation and formatting
* CSS table styling
* Media query implementation
* Navigation menu design
* Custom font integration
* Data presentation and organization

This project was completed as part of web development coursework and demonstrates responsive design principles, structured data presentation, and advanced CSS styling techniques.
